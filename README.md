# SyncThings v2.0.0

SyncThings is a powerful, modern, and lightning-fast tool for local network synchronization and communication. It allows devices on the same Local Area Network (LAN) to easily connect and share data without requiring an internet connection.

## ✨ Core Features

*   **Offline LAN Transfer:** Share files and messages securely and swiftly within your local network, without needing internet access.
*   **Clipboard Sync:** Seamlessly synchronize your clipboard across connected devices. Copy on one device, paste on another.
*   **Private Sync (Screen Sync):** Introducing a powerful new feature! Share your screen content effortlessly and invisibly across the network.
*   **Private Paste:** Bypass anti-cheat systems with an ultra-fast automated typing mechanism that simulates human input based on synchronized data.
*   **Advanced File Restrictions:** Have complete control over what gets shared with fine-grained file size and type restrictions.
*   **Synchronized Pause/Resume:** Easily pause and resume transfers and synchronizations across your devices.
*   **RTL UI:** A beautiful, modern, and fully localized Right-to-Left (RTL) User Interface for Persian users.
*   **LAN Auto-Discovery:** Seamlessly discover and connect to other SyncThings instances on your network without manual IP configuration.

## 🚀 Getting Started

1.  **Download:** Get the latest release from the [Releases](https://github.com/yourusername/SyncThings/releases) page.
2.  **Run:** Launch the application on both devices connected to the same LAN.
3.  **Connect:** SyncThings will automatically discover other devices. You can also manually connect via IP.
4.  **Sync:** Start syncing your clipboard, files, or screen!

## 🛠️ Building from Source

If you prefer to build from source, ensure you have Python 3.8+ installed.

```bash
git clone https://github.com/yourusername/SyncThings.git
cd SyncThings
pip install -r requirements.txt
python main.py
```
