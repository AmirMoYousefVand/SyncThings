# SyncThings (سینک‌ثینگز)

سینک‌ثینگز یک برنامه ساده، سبک و مدرن است که برای اشتراک‌گذاری سریع کلیپ‌بورد (متن، عکس و فایل) بین دستگاه‌های مختلف در شبکه محلی ساخته شده است.

## ویژگی‌ها

- **همگام‌سازی کلیپ‌بورد**: متن‌ها و عکس‌های کپی شده را در لحظه ارسال کنید.
- **ارسال فایل**: فایل‌ها را تنها با کپی کردن آن‌ها (Ctrl+C) ارسال کنید.
- **اتصال با کد QR**: اسکن کنید و به راحتی وصل شوید.
- **یافتن خودکار (Auto Discovery)**: پیدا کردن دستگاه‌های متصل در شبکه به صورت خودکار.
- **حالت تاریک/روشن و پشتیبانی زبان**: پشتیبانی کامل از زبان فارسی و انگلیسی.
- **امن و خصوصی**: تمام انتقال‌ها به صورت محلی در شبکه وای‌فای/لن شما انجام می‌شود و هیچ فایلی به سرورهای خارجی ارسال نمی‌گردد.

## دانلود و نصب

می‌توانید آخرین نسخه را از صفحه [Releases](../../releases) دانلود کنید. نسخه آماده اجرا (exe) برای ویندوز در دسترس است.

1. فایل `SyncThings-Windows.exe` را دانلود کنید.
2. آن را استخراج (Extract) کنید.
3. فایل `SyncThings.exe` را اجرا نمایید.

*نکته: در اولین اجرا، ممکن است فایروال ویندوز از شما دسترسی بخواهد. برای اطمینان از عملکرد درست شبکه، لطفاً اجازه دسترسی (Allow Access) را بدهید.*

## نحوه کار با برنامه

### ۱. اتصال دستگاه‌ها

روش‌های مختلفی برای اتصال وجود دارد:
- **یافتن خودکار**: به بخش **Search & Connect** رفته و روی **Search Network** کلیک کنید. سپس از لیست روی دکمه Connect کلیک کنید.
- **کد کیوآر (QR Code)**: روی یک دستگاه، بارکد نمایش داده می‌شود. در دستگاه دوم، گزینه **Scan QR Code** را بزنید تا دوربین باز شده و به آن متصل شوید.
- **آدرس IP دستی**: آدرس IP نوشته شده روی دستگاه مقابل را در فیلد مربوطه وارد کرده و Connect را بزنید.

*هنگام اتصال، روی دستگاه مقابل پیامی برای تایید یا رد ارتباط نمایش داده خواهد شد.*

### ۲. انتقال اطلاعات

پس از اتصال، تنها کافیست روی یکی از سیستم‌ها متن، عکس یا فایلی را کپی کنید (برای مثال با کلیدهای `Ctrl+C`). فایل یا متن به صورت خودکار به کلیپ‌بورد سیستم مقابل منتقل می‌شود!

## مهندسی و معماری

این پروژه با زبان پایتون و یک رابط کاربری مدرن توسعه داده شده است.

- **رابط کاربری**: CustomTkinter
- **شبکه**: TCP/UDP
  - پورت UDP 49153 برای پیدا کردن دستگاه‌ها (Discovery).
  - پورت TCP 49152 برای انتقال امن و پایدار داده‌ها.
- **مدیریت کلیپ‌بورد**: استفاده از کتابخانه `pyperclip` و درگیری مستقیم با API های ویندوز برای تصاویر و فایل‌ها.

## اجرای سورس کد

پایتون (نسخه 3.9 یا جدیدتر) باید نصب باشد.

1. دریافت کد:
   ```bash
   git clone https://github.com/AmirMoYousefVand/SyncThings.git
   cd SyncThings
   ```

2. نصب پیش‌نیازها:
   ```bash
   pip install -r requirements.txt
   ```

3. اجرای برنامه:
   ```bash
   python main.py
   ```
