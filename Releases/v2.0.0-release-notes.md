# SyncThings v2.0.0 Release Notes

Welcome to SyncThings 2.0! This major release focuses on privacy, stealth, and robust local networking.

## ✨ New Features
* **Private Sync (Screen Sync)**: Replaced HTML-based browser sync with a global hotkey that takes a high-res screenshot of the entire monitor and silently beams it to the receiver's clipboard. Leaves absolutely zero traces in browser JS engines.
* **Private Paste**: Added a dedicated hotkey to bypass strict web forms that block `Ctrl+V`. It reads your clipboard and simulates hardware keystrokes to type out the text at superhuman speeds.
* **Synchronized Transfer Controls**: You can now Pause, Resume, and Cancel massive file transfers on the fly. The UI correctly syncs the paused state across both connected devices via an out-of-band UDP control channel.
* **Advanced File Restrictions**: Added a settings panel to enforce maximum file sizes and extension whitelisting/blacklisting. Saves CPU and network bandwidth by halting invalid transfers before zip compression even begins.

## 🛠️ Bug Fixes & Improvements
* **LAN Auto-Discovery**: Fixed critical bugs where Windows Firewall and metric-routing would block UDP discovery packets over direct LAN cables without internet.
* **Smart Reconnection**: Fixed an issue where cancelling a transfer would permanently corrupt the TCP socket loop.
* **UI Polish**: Full RTL punctuation fixes for Persian dialogs, automatic black/white icon swapping for Light/Dark themes, and a new scrollable settings pane for smaller displays.
