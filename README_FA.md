# SyncThings v2.0.0

SyncThings یک اپلیکیشن ساده، سبک و مدرن برای اشتراک‌گذاری بی‌درنگ (Seamless) متن کلیپ‌بورد، تصاویر و فایل‌ها از طریق شبکه محلی (LAN) بین دستگاه‌های مختلف است.

## ویژگی‌ها

- **همگام‌سازی خصوصی (Screen Sync)**: کلید میانبر سراسری برای ثبت بی‌صدای تمام صفحه و کپی خودکار آن در کلیپ‌بورد گیرنده بدون هیچ‌گونه ردی.
- **جای‌گذاری خصوصی (Private Paste)**: کلید میانبر سراسری برای "تایپ" مخفیانه متن کلیپ‌بورد به منظور دور زدن سیستم‌های تشخیص کپی/پیست در وب و سیستم‌های ضد تقلب.
- **محدودیت‌های فایل**: تنظیم محدودیت برای حداکثر حجم فایل و پسوندهای مجاز/غیرمجاز پیش از ارسال.
- **کنترل‌های انتقال**: توقف موقت، از سرگیری و لغو انتقال در لحظه، با همگام‌سازی کامل بین هر دو دستگاه بدون قطع اتصال.
- **اصلاحات خودکار شبکه LAN**: اعمال خودکار قوانین فایروال ویندوز و هدایت پیام‌های UDP از طریق پورت فیزیکی صحیح برای اتصال آفلاین بی‌نقص در شبکه محلی.
- **بهبود رابط کاربری و راست‌چین**: پشتیبانی کامل از چینش راست‌به‌چپ (RTL) برای دیالوگ‌های فارسی، تغییر خودکار آیکون‌های روشن/تاریک، و تنظیمات قابل اسکرول.
- **همگام‌سازی کلیپ‌بورد**: متن‌ها و تصاویری که در کلیپ‌بورد کپی می‌کنید را در لحظه روی دستگاه دیگر دریافت کنید.
- **انتقال فایل (به شدت بهینه‌شده)**: ارسال آسان فایل‌های تکی و گروهی با بالاترین سرعت ممکن روی شبکه (بالای 100 مگابایت بر ثانیه روی کابل و SSD).
- **اتصال با بارکد (QR Code)**: اتصال بی‌دردسر دو دستگاه با اسکن کردن بارکد.
- **یافتن خودکار دستگاه‌ها**: دستگاه‌های داخل شبکه که برنامه روی آن‌ها در حال اجراست به صورت خودکار پیدا می‌شوند.
- **تم تاریک/روشن و دوزبانه بودن**: پشتیبانی کامل از تم تاریک و روشن همراه با زبان‌های انگلیسی و فارسی (راست‌چین).
- **امنیت بالا**: انتقال اطلاعات صددرصد در داخل شبکه محلی (WiFi/Ethernet) انجام می‌شود و هیچ فایلی روی سرورهای خارجی آپلود نمی‌گردد.

## دانلود و نصب

می‌توانید آخرین نسخه را از صفحه [Releases](../../releases) دانلود کنید.
نسخه اجرایی (exe) آماده برای سیستم‌عامل ویندوز در دسترس است.

1. فایل `SyncThings-Windows.exe` را دانلود کنید.
2. آن را در هر پوشه‌ای که دوست دارید استخراج (Extract) کنید.
3. فایل اجرایی `SyncThings.exe` را اجرا نمایید.

*نکته: در اولین اجرای برنامه، ممکن است فایروال ویندوز از شما اجازه دسترسی بخواهد. حتماً دسترسی‌های لازم را بدهید (Allow access) تا دستگاه‌ها بتوانند یکدیگر را در شبکه پیدا کنند.*

## نحوه استفاده

### ۱. اتصال دستگاه‌ها

برای اتصال سیستم‌ها به یکدیگر چند روش وجود دارد:
- **جستجوی خودکار**: به تب **جستجو و اتصال** رفته و روی **جستجوی شبکه** کلیک کنید. دستگاه‌های یافت شده در لیست ظاهر می‌شوند. روی دکمه **اتصال** کلیک کنید.
- **بارکد (QR Code)**: روی سیستم اول، به بخش **جستجو و اتصال** بروید تا بارکد شما نمایش داده شود. در سیستم دوم روی **اسکن بارکد** کلیک کرده و با دوربین سیستم آن را اسکن کنید.
- **ورود دستی IP**: آدرس آی‌پی (IP) نوشته شده در داشبورد سیستم مقابل را وارد کرده و دکمه اتصال را بزنید.

*نکته: زمانی که درخواستی برای اتصال ارسال می‌شود، دستگاه مقصد باید درخواست را تایید کند تا اتصال برقرار شود.*

### ۲. انتقال اطلاعات

به محض اینکه دو دستگاه متصل شدند، کافیست متن، یک تصویر یا فایلی را روی سیستم اول کپی کنید (با زدن `Ctrl+C`). فایل یا محتوای موردنظر شما به طور خودکار به کلیپ‌بورد دستگاه دوم منتقل خواهد شد!

## معماری و مهندسی شبکه (Performance)

نرم‌افزار SyncThings با پایتون و یک رابط کاربری مدرن (CustomTkinter) توسعه داده شده است، اما لایه‌ی شبکه آن برای انتقال داده با سرعت‌های گیگابیتی بسیار بهینه‌سازی شده است:

- **رابط کاربری (UI)**: CustomTkinter
- **لایه‌ی شبکه**: Raw TCP/UDP Sockets
  - از پروتکل UDP (پورت 49153) برای پخش پیام در شبکه و کشف دستگاه‌ها استفاده می‌شود.
  - از پروتکل TCP (پورت 49152) برای انتقال امن داده‌های اصلی استفاده می‌شود.
  - **بهینه‌سازی‌های عمیق:** استفاده از `memoryview`، بافرهای تجمیعی 4 مگابایتی برای دیسک (کاهش Fragmentation در SSD که در تست‌های لوکال تا 1.8 گیگابایت بر ثانیه سرعت می‌دهد)، تنظیمات بهینه سوکت‌های سیستم‌عامل (`SO_SNDBUF`/`SO_RCVBUF`) و دور زدن فشرده‌سازی برای فایل‌های حجیم تکی.
- **مدیریت کلیپ‌بورد**: استفاده از `pyperclip` برای متن و دستکاری مستقیم API های ویندوز برای تصاویر و فایل‌ها.

### نکات بسیار مهم درباره سرعت انتقال
اگر می‌خواهید نهایت سرعت انتقال فایل (بالای 100 مگابایت بر ثانیه) را تجربه کنید:
1. **از کابل شبکه یا روترهای 5GHz/Wi-Fi 6 استفاده کنید.**
2. **از هات‌اسپات گوشی استفاده نکنید!** هات‌اسپات‌های موبایل روی باند 2.4 گیگاهرتز به صورت Half-Duplex عمل می‌کنند (ارسال و دریافت همزمان ندارند). چون فایل باید اول از سیستم اول به گوشی برود و سپس از گوشی به سیستم دوم ارسال شود، پهنای باند دقیقاً نصف می‌شود. به همین دلیل حداکثر سرعت انتقال فیزیکی در بهترین حالت **حدود 3 الی 4 مگابایت بر ثانیه** خواهد بود و این محدودیت فیزیکی موبایل است.
3. **پروکسی و V2rayNG را متوقف کنید:** نرم‌افزارهایی مثل Proxifier یا VPN ها ترافیک شبکه داخلی (LAN) را می‌ربایند و پردازش می‌کنند. این کار باعث فشار شدید به پردازنده و قطع شدن مسیرهای انتقال سریع (Zero-copy) می‌شود. مطمئن شوید که ترافیک شبکه داخلی در این برنامه‌ها روی حالت `Direct` یا `Bypass` تنظیم شده باشد یا آن‌ها را کاملاً ببندید.

## اجرای پروژه از روی کدهای منبع

ابتدا مطمئن شوید پایتون نسخه 3.9 به بالا روی سیستم شما نصب است.

1. دریافت کدها:
   ```bash
   git clone https://github.com/AmirMoYousefVand/SyncThings.git
   cd SyncThings
   ```

2. نصب پیش‌نیازها:
   ```bash
   pip install -r requirements.txt
   ```

3. اجرای برنامه:
   ```bash
   python main.py
   ```

4. (اختیاری) ساخت فایل اجرایی (exe):
   ```bash
   pyinstaller --noconfirm --windowed --icon=app.ico --add-data "Fonts;Fonts" --add-data "app.ico;." main.py
   ```
